# Bioinformatics and reproducible investigation for genomics analysis- Homeworks
## This repository
This is the repository for the 2026 version of the course *Bioinformatics and reproducible investigation for genomics analysis*. It contains four folders, each corresponding to a unit of the course.

The program's main objective is to introduce students to methodologies and good practices in computational biology by providing them with free software tools. This to ensure reproducibility in science when doing, documenting and publishing bioinformatics projects involving genomic analysis.

The professor in charge of the course is **Dr. Ricardo Verdugo**.

The author of this repository is the student **TM. Ana Ramírez Rivas**, who belongs to the Master's program in Genetics, University of Chile.
